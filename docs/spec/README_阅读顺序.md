## 冻结的重要决定

- 不依赖每日ChatGPT对话；单人、Windows11+Edge、本地Web、免登录、SQLite和exe安装。
- **不设51天每日任务或强制打卡**；自由选择训练内容，自动记录学习历史。
- 日常听力和阅读自由查看原文、答案及解析，日常练习**不计分**。
- 严格四级模考仅统计客观题55道；写作翻译线下做、不评分、不推算425/710。
- 用户自己上传混合文件，系统自动解析校验、分题管理；数据安全与准确性优先。
- 错题每天5—10道闯关，跨日连续正确3次标记掌握。
- 每日自动备份+手动备份/恢复/导出，源码和可复现构建最终交付。
