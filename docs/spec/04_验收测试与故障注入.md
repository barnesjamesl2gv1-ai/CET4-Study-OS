# CET-4 Study OS｜验收测试与故障注入清单

> 本文件规定“必须完成的测试”，不是已经执行并通过的测试报告。  
> 核心阻断级（P0）：无法启动、错题错位/答案错、模考计时或评分错误、数据丢失、备份恢复不可信。存在P0不得正式交付。

## 1. 验收策略

- 单元测试：题型规则、选词占用、错题抽取、连续掌握、成绩统计、时序状态机。
- 集成测试：真题导入、音频资源、SQLite事务、备份及版本迁移。
- 浏览器端到端：Windows11 Edge运行，模拟用户点选、上传、关闭/刷新和计时结束。
- 故障注入：端口占用、数据库不可写、磁盘满、文件损坏、断电重启、浏览器崩溃、升级失败。
- 人工验收：用户在目标电脑使用**至少1套真实混合格式试卷**做自由训练和整套模考。
- 真题测试不得仅用“非常整齐的自编样例”代替带复杂排版的真实资源。

## 3. 模考时间边界状态测试（示例）

| 时间边界 | 允许 | 禁止 |
|---|---|---|
| 9:10前 | 查看入场须知 | 开始作文/音频/阅读正式答题 |
| 9:10—9:40 | 查看作文题，线下写作 | 提前展开听力/阅读答案 |
| 9:40—10:05 | 听力完整顺序播放、填答题卡1 | 暂停、回放、查看原文和答案 |
| 10:05—10:10 | 显示收卷阶段 | 改听力答案或提前开始阅读 |
| 10:10—11:20 | 阅读答题、查看翻译题并线下翻译 | 改听力答案、看标准答案 |
| 11:20后 | 看客观题报告和参考作文/译文 | 继续修改有效模考作答 |

## 4. 结果核验方法

**必须保存的证据**：Windows版本/Edge版本、构建号、输入样本编号与哈希、操作步骤、预期结果、实际结果、测试日志、截图/短录像（必要时）、缺陷编号及修复复测记录。

**P0缺陷示例**：导入第1套音频误连第2套；选词填空的一个词重复使用；模考提前泄露答案；页面重载仍将中断考试计分；备份文件无法解压；重装软件删除本地题库；成绩图错误把中断考次算作完成。

**可接受但必须说明的限制**：低质扫描版OCR不准确并被拦截；不支持无人确认的音频精确切分；旧式DOC需转换；作文翻译不评分；系统无法绝对防止操作系统级作弊行为。

验收标准是**可重现的客观测试结果**，不是代码能启动、网页能打开或表面无报错。
