# CET4 Study OS MVP 实机验收操作指南

> 这是**待执行指南**，不是已完成的实机测试报告。使用本人有权使用的真实试卷、解析和音频，在 Windows 11 + Microsoft Edge 上记录每步结果。

1. 从 `artifacts/CET4-Study-OS-0.1.0-Setup.exe` 安装。确认桌面快捷方式出现。双击后 Edge 打开 `127.0.0.1` 本地页面；连续双击三次应复用单个服务。检查其他电脑不能访问该服务。
2. 在“创建试卷”输入年份、6/12 月和套数。分别上传试卷、答案解析和 MP3。核对每个文件的名称、类别、内容和缺项提示；尝试重复及坏文件，记录错误反馈。
3. 对照原件人工核对听力和阅读题目、选项、答案及解析。输入阅读文章与对应题。修订一道题时填写旧题 ID，并确认历史版本未消失。
4. 在“听力片段核对”选择 MP3，逐一试听候选片段，调整起止毫秒，填写对应题号并确认。进入听力自由训练，确认分题播放、暂停、拖动、重听、查看答案可用。
5. 建立阅读训练，分别测试选词填空、段落匹配、仔细阅读。确认文章与题目同屏、选词不可重复使用、匹配可重复选同一段落。作答后关闭 Edge，重新打开并恢复已保存答案及位置。练习页面不应显示成绩。
6. 点击“立即备份”，导出 ZIP 到其他磁盘。修改一道练习答案后，选择该 ZIP 并确认恢复；刷新页面，核对原答案、试卷及音频均恢复。再试一个损坏 ZIP，确认被拒绝且现有数据不变。
7. 卸载并重装安装包，核对 `%LOCALAPPDATA%\CET4StudyOS` 中的学习记录仍可读取。记录 Windows/Edge 版本、材料哈希、截图、预期与实际结果及缺陷编号。

阻断项：导入错套、答案错位、已确认作答丢失、错误提示为已保存、备份无法恢复、卸载删除数据。发现阻断项时停止正式验收并保留材料与日志。
